# Rakeeen Portfolio

A premium, minimalist editorial portfolio for digital architects and designers. Built with React, Vite, and Firebase, featuring hyper-stark aesthetics and precision-engineered interfaces.

## 🚀 Key Features
- **Dynamic Content:** Powered by Firebase Firestore for real-time updates.
- **Multilingual Support:** Full support for English, Arabic (RTL), and Italian.
- **Modern Tech Stack:** React 19, Vite 6, GSAP for animations, and Lucide icons.
- **Responsive Design:** Fluid layouts that adapt perfectly to all screen sizes.
- **Administrative Dashboard:** Integrated management system for projects and site configuration.

## 🛠 Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Animations:** GSAP, Motion
- **Styling:** Vanilla CSS (Modern CSS Variables)
- **Database:** Firebase Firestore
- **Deployment:** GitHub Pages / Firebase Hosting

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/hamed-uxdesign/Rakeeen.git
   cd Rakeeen
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Copy `.env.example` to `.env` and fill in your Firebase configuration.
   ```bash
   cp .env.example .env
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 🏗 Build & Deploy
- **Build for production:** `npm run build`
- **Deploy to GitHub Pages:** `npm run deploy`
